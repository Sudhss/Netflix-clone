# Netflix Clone

A beautiful, responsive Netflix clone built with **HTML and CSS only**. This project recreates the Netflix homepage with modern design principles and smooth animations.
The sole purpose of making it was revising HTML CSS when i started out with web dev.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, Netflix-inspired design with smooth animations
- **Hero Section**: Featured content with background image and call-to-action buttons
- **Movie Categories**: Multiple rows of movie/show cards with horizontal scrolling
- **Navigation**: Fixed navigation bar with Netflix logo and menu items
- **Footer**: Complete footer with social links and legal information
- **Hover Effects**: Interactive elements with smooth transitions
- **Cross-browser Compatible**: Works on all modern browsers

## Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Enjoy** your Netflix clone!

No build process, no dependencies, no setup required - just pure HTML and CSS

## Key CSS Features

- **Flexbox Layout**: Modern CSS layout system
- **CSS Grid**: For complex layouts
- **CSS Variables**: For consistent theming
- **Media Queries**: Responsive design
- **CSS Transitions**: Smooth animations
- **CSS Gradients**: Beautiful overlays
- **Box Shadows**: Depth and elevation

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: 480px - 767px
- **Small Mobile**: Below 480px

## Color Scheme

- **Primary Background**: #141414 (Netflix dark)
- **Text**: #ffffff (White)
- **Secondary Text**: #e5e5e5 (Light gray)
- **Accent**: #b3b3b3 (Gray)
- **Buttons**: #ffffff (White) and rgba(109, 109, 110, 0.7)

## Customization

### Changing Colors
Edit the CSS variables in `styles.css` to match your brand colors.

### Adding More Categories
Simply duplicate the category section in `index.html` and update the content.

### Changing Images
Replace the placeholder images with your own movie/show images.
